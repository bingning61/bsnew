| 文件 | 用途 |
| --- | --- |
| `00_thesis_outline.md` | 论文总体提纲，包含拟题目、摘要要点、关键词、章节结构、代码依据、不能写内容和待补材料 |

| `03_motion_control.md` | 第 3 章控制方法，说明视觉偏差控制、速度输出和目标丢失停车 |
| `04_simulation_and_system.md` | 第 4 章系统实现，说明 ROS1/catkin、Gazebo 支撑、机器人模型、场景和运行流程 |
| `05_experiment_and_result.md` | 第 5 章实验验证，整理可做实验、当前材料边界和需要补充的截图/数据 |
| `06_conclusion.md` | 第 6 章总结与展望，概括已有工作、不足和后续改进方向 |
