## 使用边界

本文草稿只确认以下主线：图像输入、YOLOv5 目标检测、检测框中心表征、图像中心偏差构建、基于偏差的速度控制、零速度安全停止、底盘接口和 Gazebo 仿真支撑。

后续任何 AI 继续写作时，都必须以当前代码事实为准，不得沿用旧阶段草稿中的过时技术路线。当前项目真实主链路应统一理解为：

图像输入
→ YOLOv5 检测焊缝目标框
→ 提取检测框横向中心
→ 结合图像宽度构造位置表征
→ 与图像中心形成横向偏差
→ 控制节点输出 Twist 速度指令
→ 底盘接口或 Gazebo 执行
→ 无检测或超时时输出零速度

本文草稿没有写入以下未确认内容：Mask R-CNN、UWB、IMU 参与闭环、多传感器融合、卡尔曼滤波、滑模控制、全局路径规划、工业现场测试、完整实机部署、检测准确率、mAP、平均误差、FPS、PID/Stanley 对比实验、三维重建、中心线拟合和相机外参标定结论。

如果这些内容只作为“禁止写入”的边界说明存在，可以保留；但不得继续在后续写作提示中写成“当前正文可以往这个方向展开”。

## 推荐阅读顺序

先阅读 `01_论文题目摘要关键词.md` 和 `02_论文目录与写作说明.md`，确认论文题目、五章结构、当前真实技术路线以及第一章不同部分的引用写法；随后依次阅读第一章至第五章；若需要快速查看完整正文，打开 `11_论文正文合并版.md`；若需要查看公式显示效果，打开 `13_论文公式预览版.html`。

## 仍需人工补充

第四章涉及实验验证，但交接材料未提供定量实验结果。因此正式定稿前必须补充识别截图、检测框可视化图、中心偏差输出、速度输出、Gazebo 仿真截图、实机运行照片或视频、权重文件说明和实验结果表格。具体清单见 `08_待补充材料清单.md`。
